## One source of truth

Everything on this site is published straight from the
[SpaceWorks-Design](https://github.com/SpaceWorks-HQ/SpaceWorks-Design) repository. Add it to any Space Works
project as a git submodule and every surface draws from the same kit:

```bash
git submodule add https://github.com/SpaceWorks-HQ/SpaceWorks-Design.git design
```
