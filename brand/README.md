# Space Works brand kit

Exported from the connected Figma file on 15 October 2026 using Figma MCP Go+.

- `space-works-brand-guidelines-v1.pdf`: all 17 guideline pages.
- `guidelines/svg/` and `guidelines/png/`: the same pages individually, numbered in presentation order. SVG text is outlined; PNGs are 1440 × 1000.
- `logo-masters.svg` and `.png`: the complete logo and styles sheet.
- `figma-styles.json`: source node IDs, component bounds, seven paint styles and ten text styles.
- `../logo/`: ten SVG masters and matching 4× PNGs, including primary, horizontal, symbol and app-tile variants.
- `../icons/`: favicon, app icons and social preview.
- `../mascot/`: Patch, the painted wolf mascot, cut from its two concept sheets and traced to vector SVG (hero, sneeze loop, walk cycle and every frame, with PNGs and animated WebPs), plus the original pixels and compressed copies. Added after the Figma export; see `../mascot/README.md`.
- `../tokens/`: reusable CSS and JSON tokens. `../fonts/`: web fonts and provenance.

Use full color on light surfaces, reversed cream on dark surfaces, and the dedicated ink mark for single-color use. Monochrome versions preserve a hollow opening and transparent folds; do not create them by recoloring the full-color logo. Keep a quarter of the symbol height clear on every side.

Gilroy is the primary family. Unbounded is a secondary accent for one short expressive phrase per layout. Citron can fill selected sections; warm yellow is a small accent with Deep Ink text. Preserve the seven exact colors in the tokens.

These are portable assets and style records. Editable native components remain in Figma; this export is not a `.fig` backup. Printed color and Illustrator import have not been proofed.
