# Screenshots

`ux/` holds screenshots of Space Works UX in a real Space Works product, used by the design site's UX pages.

- **Source:** SpaceWorks-Events at `origin/dev` `03186e0`, run locally with demo data (no real people or data).
- **Naming:** `<screen>-<desktop|phone>-<light|dark>.webp`. Desktop is 1280×800, phone is 390×844, both at 1×.
- **Refresh:** re-capture whenever the patterns change, keeping the same names so the site picks them up.
